# АГАТУ КТиУ — расписание через интернет

Это версия JavaScript-приложения для размещения на интернет-хостинге. После публикации одну HTTPS-ссылку можно открыть на телефоне и компьютере без установки программы. Просмотр расписания и PDF доступен всем, а две кнопки обновления защищены паролем владельца.

**Приложение ещё не размещено.** Упаковка файлов не создаёт работающий адрес в интернете: нужно один раз загрузить исходники на хостинг. Ниже показан путь через GitHub и Render. Оба сервиса имеют собственные учётные записи. Аккаунты и пароль должен создать владелец сайта; в архиве их нет.

## Как разместить — пошагово

1. Распакуйте весь ZIP. В полученной папке видны `Dockerfile`, `server.mjs`, `package.json`, `data`, `lib`, `public` и `vendor`.
2. Создайте репозиторий на https://github.com/new . Можно выбрать **Private**. Откройте новый репозиторий и нажмите **Add file → Upload files**. Перетащите **содержимое** распакованной папки в корень репозитория так, чтобы `Dockerfile` оказался на верхнем уровне, затем нажмите **Commit changes**. Не загружайте сам ZIP вместо файлов. GitHub поддерживает перетаскивание папки в окно загрузки: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository .
3. Откройте https://dashboard.render.com/ , войдите в аккаунт, нажмите **New → Web Service** и подключите этот репозиторий GitHub. Выберите среду **Docker**, корень проекта — корень репозитория, Dockerfile — `Dockerfile`. Команда запуска уже прописана в Dockerfile; дополнительные команды установки не нужны.
4. В настройках сервиса добавьте **секретную переменную среды** `ADMIN_TOKEN` со своим длинным паролем (не менее 16 символов, лучше 24 и более). **Не записывайте пароль в исходный код или репозиторий.** Dockerfile уже включает `PUBLIC_MODE=1` и папку данных `AGATU_CACHE_DIR=/var/data/agatu`. Render автоматически задаёт `PORT`.
5. Для постоянного хранения проверенных PDF выберите платный веб-сервис Render и добавьте **Persistent Disk** с точкой подключения **`/var/data`**. Именно туда приложение сохраняет загруженные файлы. На бесплатном плане диск недоступен: сайт можно опробовать, но после остановки или перезапуска вернётся встроенная копия PDF от 05.10.2026, и потребуется снова нажать две кнопки обновления. Документация: https://render.com/docs/disks и https://render.com/docs/free .
6. Нажмите **Create Web Service** / **Deploy**. Когда сборка завершится, Render покажет HTTPS-адрес вида `https://ваше-название.onrender.com`. Откройте этот адрес на телефоне через мобильный интернет и на компьютере. Настраивать роутер или оставлять домашний компьютер включённым не требуется.
7. Один раз выполните **«Скачать актуальные PDF»**, затем отдельно **«Проверить и составить расписание»**. При нажатии появится окно ввода вашего пароля. Посетителям он не нужен. Вкладка хранит пароль только в оперативной памяти до перезагрузки страницы; браузер его не записывает в настройки.

Подробные шаги Render: https://render.com/docs/web-services . В настройке **Health Check Path** можно указать `/api/health`.

## Ссылка на вашем существующем сайте

Добавьте кнопку «Расписание преподавателей» и вставьте полученный адрес `https://…onrender.com`. В Google Сайтах это делается в редакторе через **Вставка → Кнопка → Ссылка → Опубликовать**: https://support.google.com/sites/answer/90538 . Приложение откроется отдельной страницей с полноценным интерфейсом. Для встраивания интерфейса внутрь рамки другого сайта потребуется отдельная настройка разрешённых доменов; эта сборка настроена для открытия по ссылке.

Не загружайте `index.html` в Google Сайты как отдельный файл: кнопки обновления обращаются к запущенному серверу JavaScript. Публичный адрес предоставляется хостингом, а Google Сайт ведёт к нему.

## Как работает обновление

- **Скачать** — находит текущие семь ссылок в разделе КТиУ → Очно на официальной странице АГАТУ, скачивает полный набор PDF. Старое расписание остаётся на экране.
- **Проверить** — проверяет SHA-256 и разбирает сохранённые PDF; только успешный целый набор становится общим расписанием для всех посетителей.
- Источники и время получения можно посмотреть в интерфейсе. Если внутренняя версия PDF изменилась при прежней ссылке, скачивание получит новые байты и сохранит новый SHA-256.
- Данные от 05.10.2026 включены как исходная копия. Не считайте её расписанием текущей недели; обновите документы после развёртывания.
- Длинный субботний блок Федорова П.И. сохраняется одной карточкой, а счётчик учитывает две пары по интервалам из того же PDF.

Доступ к кнопкам обновления защищён `ADMIN_TOKEN`. Посетители могут открывать расписание, локальные PDF, отчёт, CSV и календарь. Пароль задаётся только в Render. Если потеряли его, замените значение переменной в настройках сервиса и перезапустите размещение.

## Что входит в архив

| Файл / папка | Назначение |
|---|---|
| `Dockerfile`, `.dockerignore` | Собирают сервер Node.js для интернет-хостинга без установки npm-пакетов в работающий контейнер. |
| `server.mjs` | Публичный HTTP API, проверка пароля, чтение активного набора, раздача интерфейса и PDF. |
| `lib/` | Поиск очных источников, скачивание, разбор таблиц и сохранение целых наборов. |
| `public/` | Адаптивный интерфейс, поиск преподавателей, фильтры, выгрузки и окно пароля. |
| `data/` | Встроенная копия семи PDF и их SHA-256 от 05.10.2026. |
| `vendor/` | PDF.js и шрифты: читают PDF целиком на JavaScript. |
| `package.json`, `package-lock.json` | Версия Node.js, команды и тестовые зависимости; обычная работа не требует установки npm-пакетов. |
| `tests/` | Автоматические проверки, в том числе защита обновлений в публичном режиме. |
| `reports/tests_web.txt` | Итоговый вывод 39 тестов публичной сборки. |
| `README_LOCAL.md`, Windows `.bat` | Инструкция и запуск того же приложения на одном компьютере без хостинга. Для локального режима не задавайте `PUBLIC_MODE=1`. |
| `THIRD_PARTY_NOTICES.md` | Лицензии сторонних компонентов. |

Для разработчика локальный запуск: `node server.mjs --open`. Публичный запуск без Docker: установите Node.js ≥24.5, задайте `PUBLIC_MODE=1`, `ADMIN_TOKEN`, `AGATU_CACHE_DIR` и `PORT`, затем выполните `node server.mjs`. Сервер слушает `0.0.0.0:PORT`, а HTTPS обеспечивает внешний хостинг. Не открывайте этот порт напрямую без HTTPS-прокси.

## Ограничения

Доступность сайта и хранение обновлённых PDF зависят от тарифного плана хостинга. На бесплатном Render служба может засыпать, первый заход после простоя будет медленнее, а сохранённые данные исчезнут при остановке. Платный план с диском сохраняет PDF после перезапуска. Изменение формата официальных PDF может потребовать обновления парсера; при ошибке он не заменяет проверенный набор неполным расписанием.
