# Расписание АГАТУ КТиУ — JavaScript

Приложение для расписания преподавателей Колледжа технологий и управления АГАТУ. Только очная форма обучения. Интерфейс работает в браузере, скачивание и разбор PDF выполняет локальный сервер на JavaScript / Node.js. Python не нужен.

## Установка и запуск на Windows

1. Установите **Node.js LTS версии 24.5 или выше** с официального сайта: https://nodejs.org/en/download . Подходит актуальная ветка 24 LTS. После установки заново откройте окно запуска приложения.
2. Нажмите правой кнопкой на ZIP → **Извлечь всё**. Сохраните всю папку приложения, например в `Документы\АГАТУ_расписание`. Не запускайте файл прямо из окна ZIP.
3. Откройте **Запустить приложение.bat**. Если Windows предупреждает о скачанном файле, разрешайте запуск только полученного вами архива.
4. Подождите несколько секунд. Откроется браузер с адресом `http://127.0.0.1:8787`. Если браузер не открылся, скопируйте адрес из окна запуска; занятый порт может замениться на 8788–8797. На странице должна быть надпись **«Версия 1.3»**.
5. **Оставьте окно запуска открытым**, пока пользуетесь расписанием. Чтобы завершить работу, закройте это окно. Закрытие вкладки браузера само по себе сервер не останавливает.

Устанавливать npm-пакеты для обычного запуска не нужно: PDF.js и шрифты уже включены в архив. `start.bat` — второй файл запуска с теми же командами и именем без кириллицы.

Если старая версия осталась открытой на порту 8787, новая запустится на свободном порту (например, 8788). Не пользуйтесь старой вкладкой 8787: смотрите адрес в новом окне запуска и надпись «Версия 1.3». Надёжнее сначала закрыть все старые окна запуска и распаковать новый ZIP **в отдельную папку**, затем запустить `.bat` из неё. Если по-прежнему видны две кнопки или ошибка «Проверка не пройдена» из-за одной записи, запущена старая версия.

На macOS / Linux: установите Node.js, откройте терминал в папке приложения и выполните `node server.mjs --open`. На macOS также можно запустить `Запустить приложение.command`; при необходимости сначала выполните `chmod +x "Запустить приложение.command"`.

## Как пользоваться

1. Выберите преподавателя слева или введите фамилию / полное ФИО. Поиск понимает инициалы и полное имя: например, «Федоров П.И.» и «Федоров Павел Иванович». Нажмите Enter, чтобы выбрать первое совпадение. Имена берутся из PDF; поиск не определяет неизвестные ФИО вне этих документов.
2. Выберите неделю. «Все даты из PDF» показывает все опубликованные даты. Кнопки дней ограничивают карточки выбранным днём.
3. По умолчанию включено **Без кураторского часа**. Снимите галочку, чтобы показать и его.
4. В карточке видны дата, время, дисциплина, группы, кабинет и ссылка на конкретную страницу локального PDF.
5. **CSV** выгружает выбранного преподавателя за выбранную неделю с учётом кураторских часов. **Календарь** создаёт ICS для календарного приложения, время — Якутск (UTC+9). Эти выгрузки охватывают всю выбранную неделю, даже если открыт один день.
6. Значок печати печатает текущие показанные карточки; можно выбрать «Сохранить как PDF» в окне печати браузера.
7. **Источники расписания** открывает список семи документов. «Локальный PDF» — именно файл, по которому составлены текущие карточки; ссылка на сайт — опубликованный оригинал, который уже мог измениться.

Последний преподаватель и настройка кураторских часов сохраняются в браузере. При проверке нового набора выбирается основная неделя новых PDF.

## Одна кнопка обновления

Нажмите **«Обновить расписание»**. Приложение само открывает официальную страницу https://agatu.ru/obuchauschimsya/raspisanie/ , находит семь ссылок в разделе **Колледж технологий и управления → Очно → Расписание занятий**, скачивает все PDF и затем анализирует их. Если ссылка осталась прежней, но содержимое PDF изменилось, загружаются новые байты и обновляется SHA-256. На время обновления прежнее расписание остаётся на экране.

Если скачать хотя бы один PDF не удалось, прежнее расписание сохраняется. Если PDF скачаны, но в одной записи нет времени, эта запись пропускается; остальные занятия показываются, а предупреждение указывает источник и страницу. Если целая страница или отдельный источник не распознаны, доступны занятия из остальных страниц и источников. **Результат с предупреждениями может быть неполным:** обязательно прочитайте отчёт и сверьте нужные занятия с PDF. Когда не распознано ни одного занятия, прежнее расписание остаётся активным.

Автоматического скачивания по таймеру нет: обновление запускается отдельной кнопкой. Открытие приложения само по себе не обращается к сайту АГАТУ.

## Работа без интернета

В архив включены PDF, полученные **5 октября 2026 года в 14:29 по Якутску**, и их контрольные суммы. Первый запуск доступен без интернета после установки Node.js. После успешного обновления приложение открывает последний обработанный набор. Просмотр сохранённого расписания, локальных PDF, выгрузки и печать доступны офлайн.

Для получения новых документов нужен интернет. Сохранённая копия не гарантирует актуальность: смотрите время получения PDF внизу страницы и нажимайте «Обновить расписание».

Новые наборы сохраняются в домашней папке пользователя: `.agatu_schedule_js/v1` (на Windows обычно `C:\Users\Имя\.agatu_schedule_js\v1`). Распаковка новой версии в другую папку не удаляет эту историю. Наборы постепенно занимают место на диске. Чтобы полностью сбросить сохранённые данные, закройте приложение и удалите эту папку: следующий запуск откроет встроенную копию. Настройки интерфейса хранятся отдельно в браузере.

## Как читается расписание

Парсер учитывает линии таблиц и координаты текста, объединённые ячейки, отдельные строки преподавателей и кабинетов, несколько групп, запятые вместо точек после инициалов и разные написания времени. Общий блок для двух групп не дублируется.

Даты сохраняются **буквально из PDF**. Если в одном документе указаны разные недели, приложение показывает предупреждение и разделяет даты по неделям. Оно не переносит старую дату на новую неделю по догадке.

В копии от 05.10.2026 у Федорова П.И. **19 карточек из PDF и 20 пар по опубликованным интервалам**. В субботу в юриспруденции напечатан один длинный блок `12:00–15:35`: интервалы `12:00–13:35` и `14:00–15:35` есть в том же PDF, поэтому счётчик учитывает две пары. Карточка и выгрузки сохраняют один исходный блок. Если документ не содержит подтверждающих коротких интервалов, длительность не делится на пары по предположению.

Эта версия проверена на сентябрьских и октябрьских таблицах АГАТУ. При существенном изменении структуры таблиц или замене текстового PDF сканом потребуется доработка парсера. Неизвестная таблица или запись без времени отмечаются в отчёте, а распознанные занятия остаются доступными. Отсутствие карточки не подтверждает отсутствие занятия: при предупреждениях сверяйтесь с исходным PDF.

## Если что-то не работает

| Что произошло | Что сделать |
|---|---|
| Открылся `index.html`, кнопки не работают | Запустите `.bat` или `node server.mjs --open`. Файл HTML не запускает сервер скачивания и PDF-парсер. |
| `node` не найден | Установите Node.js LTS, закройте старое окно запуска и запустите заново. Проверьте `node --version` в новом терминале. |
| Снова сообщения «… is not recognized» | Распакуйте весь новый архив. В этих `.bat` команды записаны ASCII с Windows-переносами строк. Не заменяйте файл запуска старой версией из предыдущего архива. Можно открыть `start.bat`. |
| Браузер сообщает, что сервер недоступен | Окно запуска должно оставаться открытым. Запустите его снова и используйте адрес, который оно вывело. |
| Обновление завершилось ошибкой скачивания | Откройте отчёт: там указан источник. Проверьте интернет и доступность официальной страницы, затем повторите «Обновить расписание». Старые карточки остаются доступными. |
| Появилось предупреждение о пропущенной записи или странице | Откройте отчёт и сверьте эти занятия с исходным PDF. Остальные распознанные занятия показаны. |
| Мало занятий или пустой день | Проверьте преподавателя, неделю, фильтр дня и кураторского часа. Сравните с локальным PDF в карточке. |
| После установки остались две кнопки или та же ошибка | Проверьте надпись «Версия 1.3». Закройте старое окно запуска, распакуйте новый ZIP в отдельную папку и откройте новый `.bat`. Если старая версия ещё работает на 8787, пользуйтесь адресом нового окна (обычно 8788). |
| Предупреждение про разные недели | Посмотрите отчёт. Даты уже так напечатаны в источнике; приложение их не исправляет. |

Сервер доступен только на этом компьютере (`127.0.0.1`). Для доступа друзей по общей интернет-ссылке приложение потребуется разместить на хостинге с Node.js и HTTPS. Размещение одного `index.html` на статическом сайте не обеспечивает работу этого сервера.

## Команды для разработчика

Из папки приложения:

```sh
node server.mjs --open
node cli.mjs update --report проверка.txt
node cli.mjs download
node cli.mjs check --report проверка.txt
node cli.mjs current
```

`--cache путь` задаёт отдельную папку данных для CLI. Для автоматических тестов потребуется установить **только зависимости разработки**:

```sh
npm ci
npm test
```

Исходники приложения полностью на JavaScript. Контрольные JSON подготовлены независимо до упаковки; для работы приложения и выполнения тестов Python не требуется.
